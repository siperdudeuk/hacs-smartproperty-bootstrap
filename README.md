# Smart Property Software Bootstrap

Home Assistant integration that pairs your instance with the
[Smart Property Software](https://www.smartpropertysoftware.com) control plane.
Once paired, the integration periodically uploads an inventory snapshot and
executes signed deployment jobs — typically dashboards and automations
generated by the SPS AI builder.

## What it does

1. **Pair** — a one-time pair code from the SPS admin dashboard links this HA
   instance to a client account. The code is exchanged for a long-lived token
   stored in this integration's config entry.
2. **Sync** — every 60 s (configurable) the integration uploads an inventory
   snapshot (entities, devices, areas, dashboards, automations) to the control
   plane. This is what the AI builder uses to know which entities are
   available.
3. **Execute jobs** — every 30 s (configurable) the integration polls for
   pending jobs. Each job is HMAC-SHA256 signed with the pair token;
   signatures are verified before anything is applied.

## Supported job types (v0.1)

| Operation | Effect |
|---|---|
| `dashboard_proposal` | Overwrites the config of an existing Lovelace dashboard |
| `automation_proposal` | Inserts or updates an entry in `automations.yaml` and reloads |
| `rollback` | Restores dashboards and automations from a prior inventory snapshot |

Scripts, scenes, and helpers (`input_*`, `counter`, `timer`) are planned for
v0.2.

## Installation

### Via HACS (recommended)

1. In HACS, open **Integrations → ⋮ → Custom repositories**.
2. Add `https://github.com/smartpropertysoftware/hacs-smartproperty-bootstrap`
   with category **Integration**.
3. Install "Smart Property Software Bootstrap".
4. Restart Home Assistant.
5. Go to **Settings → Devices & Services → Add Integration** and search for
   "Smart Property Software Bootstrap".
6. Paste the pair code from your SPS admin dashboard.

### Manual

Copy `custom_components/smartproperty_bootstrap/` into your HA config
directory under `custom_components/`, then restart HA.

## Security model

- Only the pair code is entered into Home Assistant. The control plane
  responds with a per-instance token that never leaves the HA config entry.
- Every deployment job includes an HMAC-SHA256 signature derived from the
  pair token. Unsigned or invalid jobs are rejected.
- All network traffic is outbound HTTPS — no inbound ports are opened.
- The integration only writes to Lovelace dashboards that already exist and
  to `automations.yaml`. It does not touch `configuration.yaml`, secrets, or
  the HA auth system.

## Configuration

After pairing, the integration's **Configure** button lets you change:

- **Job poll interval** (default 30 s) — how often pending jobs are fetched.
- **Inventory sync interval** (default 60 s) — how often the snapshot is
  uploaded.
